晨间看板 · Windows 桌面版（Windows 10 / 11，64 位）

这是什么
========
这是桌面挂件，不是 PWA 图标，也不是普通浏览器窗口。
启动后默认是约 5×5 厘米的紧凑面板，突出显示天气、下一节课程（含教材）和待办；放大后显示物品、日期切换、更多待办以及导入和播报设置。
普通应用会盖在看板上方：要查看就回到桌面，不会挡住正在工作的窗口。
看板所在区域会覆盖该区域的桌面图标，请把看板拖到空白位置。

首次使用
========
1. 右键 ZIP → 全部解压。不能只从压缩包里双击 exe。
2. 推荐双击 Install.cmd（只给当前用户安装，不需要管理员权限）。
   它将文件复制到 %LOCALAPPDATA%/MorningBoardDesktop/Program 并启动。
   也可双击 MorningBoard.exe 便携运行；开启登录后显示后，不要随意移动这个文件夹。
3. 回到 Windows 桌面查看。顶部“设置” → 勾选“登录后自动显示”。
   以后登录这个 Windows 用户后自动出现，不必再点开 App。
   “开机显示”实际是 Windows 用户登录后，不是登录屏幕或锁屏。
4. 紧凑面板中按住顶部“晨间看板”区域可移动位置；点击天气卡右上角“展开”可放大并显示更多信息，再点“收起”回到约 5×5 厘米。
   拖动右下角“◢”改变面板大小，松手自动记住位置和大小；放大/缩小时布局会自动切换，重启后恢复。
   顶部“...”菜单 → 面板大小，可直接选紧凑、小、中、大；也可锁定位置和大小。
   放大状态下长内容可上下滚动。
   顶部设置还可重新加载、恢复主屏位置、暂时隐藏或退出。
   托盘（时钟旁边，可能在折叠箭头中）也有同样的菜单。

日期与待办
==========
看板顶部点“前一天 / 后一天”或直接选日期，课程、物品、待办一起切换。
点“今天”返回；天气始终是今天，未录入课表的日期不会冒充没课。
在待办框直接输入，按回车或点“添加”即可；勾选完成，点“删除”移除临时待办。
待办和物品勾选按日期保存在本机；切换日期不会把完成状态混到别的日期。
未提交的待办草稿在本次页面内按日期保留，刷新前请先添加。

天气与数据
==========
网页来自本机 app 目录，不依赖本地网页服务器或 GitHub 网站是否在线。
天气仍需要网络；首次点“定位并查询”后由宿主询问是否允许定位。
允许会记住，下次可自动查询；拒绝可再次点击重试。常驻期间按 1 小时缓存更新。
天气来自 Open-Meteo，不读取 Windows 自带天气应用的数据。
Windows 定位开关、网络和天气服务故障仍会影响结果，不能保证永不失败。

桌面版和 Chrome/Edge/手机的数据不自动同步！
浏览器已导入的课表、临时待办、勾选状态不会自动搬过来。
网页设置可导出“课程、物品与计划”，桌面版中重新导入即可。
此导出不含临时待办、勾选、定位、语音设置。
也可修改安装目录 app/data 中的 JSON，再从顶部设置“重新加载数据”。
更新安装保留已有 data JSON；导入数据优先于文件，可重新导入来替换。
随包默认课表是教学安排表中的第 5–17 周，共 29 条循环课程规则，按周次与单双周筛选。
更新不会强制覆盖已有课表：放大看板 → 设置 → 导入数据 → 选择“整学期课程更新.json”，
预览 29 条课程并确认。此文件只替换课程，保留教材和待办。
第 9–10 节未提供钟点，保留节次并显示“时间待确认”，不猜上课时间。

导入 Excel
==========
放大看板后，在设置的数据导入中选择 .xls、.xlsx 或 .json 文件，先预览再确认。
你提供的教务系统 HTML 型 .xls 课表可直接识别；普通表格请先下载页面里的 Excel 模板。
模板有课程、教材、待办三张表；只导入课程时可在类型中选择“课程”。
识别不了的布局会提示，不会猜测或覆盖原数据；Excel 文件在本机读取，不上传。

运行条件与当前限制
==================
需要 .NET Framework 4.8 与 Microsoft Edge WebView2 Runtime。
本机已检测到两者；其他电脑缺少时请从微软官方站点安装 WebView2 Runtime。
离线也可看本机课表、物品和待办；天气需要联网。语音取决于系统中文音色。
这是未签名的个人工具，Windows 可能显示安全提示；请核对来源，不要全局关闭保护。

桌面图标层嵌入依赖 Explorer 的窗口结构，并非微软稳定的公开小组件 API。
已做隐藏窗口挂接、页面加载测试；人工拖动、多屏、显示桌面、重启登录需在实际电脑验证。
若桌面层不可用，会提示失败并保留托盘，不会偷偷变成普通 App 窗口。
Explorer 重启后会尝试恢复显示；企业策略或第三方桌面软件可能限制这一机制。
安卓桌面小组件仍未实现；本包只解决 Windows。

退出、停用、卸载
================
仅暂时关闭：顶部设置/托盘 → 退出。
取消自动显示：取消“登录后自动显示”勾选，再退出。
卸载：取消自动显示并退出后，删除 %LOCALAPPDATA%/MorningBoardDesktop/Program。
用户数据在 %LOCALAPPDATA%/MorningBoardDesktop/WebView2，位置和大小设置是 window.json。
想保留待办/勾选就别删 WebView2；清空整个 MorningBoardDesktop 才会删掉这些本机数据。
失败日志：%LOCALAPPDATA%/MorningBoardDesktop/desktop.log。
