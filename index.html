    手机与电脑：安装和显示方式

    这是可离线打开的网页应用；安装并不等于桌面小组件。

    安卓：用系统 Chrome 打开本站，在菜单中选择“安装应用”或“添加到主屏幕”（以实际菜单为准）。得到的是入口图标，需点开查看；目前不能直接在手机桌面显示数据。

    Windows 电脑：用 Chrome 或 Edge 打开本站，在浏览器菜单的应用相关入口安装；安装后是独立看板窗口，可手动固定到任务栏。当前没有桌面常驻、开机自启或置顶功能。

    如果要桌面直接显示天气和课表，需要另做安卓桌面小组件，电脑也需要桌面程序支持。网页不能自行取得这些系统权限。
